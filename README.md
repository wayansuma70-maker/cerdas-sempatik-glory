# CERDAS — Cerita Digital Anak Sempatik (SMP Negeri 3 Kediri)
Aplikasi refleksi 4F (Facts, Feelings, Findings, Future). Frontend statis (GitHub Pages) + backend Google Apps Script (REST API).

```
index.html      ← halaman utama (harus di root repo)
css/style.css   ← gaya
js/config.js    ← ⚠ isi GAS_URL di sini
js/api.js       ← komunikasi fetch() ke Apps Script
js/app.js       ← logika aplikasi
```
Panduan lengkap: lihat `PANDUAN-INSTALASI.md`. Berkas backend (`Kode.gs`) sengaja tidak disertakan di repo ini.
